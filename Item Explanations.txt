2. Widths of the floor
3. Lengths of the floor
4. Windows coordinates: every floor seprator ~, every window in a list, 
each block in (): coordinates of windows in the form
x1-y1;x2-y2
All floor will be as:
(0-0;30-0),(30-0;30-20),(30-20;0-20),(0-20;0-0)

Example:
[(0-0;0-20),(0-20;70-20),(70-0;70-20),]~

5. Items:

1ID, 2Name, 3Must, 4Room, 5width, 6length, 7Priority, 8Neighbores, 9Fix, 10FixX, 11FixY, 12Corridor, 13Path, 14Proximity, 15Additional, 16MaxArea, 17PathEntrance, 18NeedWindow, 19MaxH/MaxW, 20MinDistance, 21floorId, 22Threshold

1) ID - id of the item, integer,  used as i in the code 
2) Explanation, item name, string
3) MUST - is this item mandatory on this floor, boolean, used as _MUST1
4) ROOM - is it room and must be used on objective, boolean, _Room1
5) minimal width, int, foots, w_i 
6) minimal lenght, int, foots, h_i
7) Priority, int (minimal is -1), _priority - the less, the more important is this object 
8) neighbors(), list of ints, items that shuold have common wall with current (symmetric)
9) fixed, is fixed position, boolean, does it has predefined position  
10)fixed x, empty or int, fx_i - fixed x coordinate of the top right 
11)fixed y, empty or int, fy_i - fixed y coordinate of the top right 
12) corridor, is this item corridor, boolean,_Corridor1
13) Must have a path, does this item has a path to entrance, boolean, Must_have_a_path
14) proximity constraint[;] , pair of int pairs (p_x_(foot,inch),p_x_(foot,inch)), do we have another object  in the given distance
15)_Additional_Constraints1[;], list - number of items with aspect ratio?
16) Max Area, empty or int, max_area - the max value of the item area (foots-squared)
17)_May_Have_a_path_to_enterence1? && _Neighbours_to_path_to_enterence1, if Null - no path, else list of ints - 
path to the entrance 
18) need windows - does item require window, boolean
19) [max widht; max lenght], pair of int pairs (w_(foot,inch),h_(foot,inch)), maximum values of widths and lengths.
20) _Min_Distance_Constraints[ID-distance], dictionary to represent minimal paramters
21)floor id, empty or int - do we have fixed floor for the item
22) room thershold, int (foots), the wall threashold for furnitures items to be counted as spaces

Subitems explanations:

1) item_id - int, item to which it belongs; 
2) subitem_id - int, subitem number; 
3) subitem_name - string, subitem name; 
4) lenght - int, foots, (minimal length)
5) width - int, foots, (minimal width)
6) rotatable - boolean, can we rotate it (four directions right now)
5) anchor - tuple of 4 ints, where to put subitem relatively to walls; 
6) padding - tuple of 4 ints, free obligatory subitem space; 
7) stack - (stacked with, anchor side of stack) - could be placed on top of other item, place where to be placed - 
int (subitem to be placed), (int, int,int, int) - tuple of 4 ints, where to put subitem relatively to current item;
  
8) stretch - (streching sub items until a certain distance, it can be seperable, adjaceny), to which sizes stretched, can be separated - 
  float - Max size to stretch, None or float - Min size to stretch, boolean - can be adjuscent;

9) consider_as_free_space - boolean or empty
10) can_not_be_placed_on_windows_side - boolean
11) door_face, int or empty, -1 - any, 0-3 side - to in front place of the door
12) pillow_side, int or empty, -1 - any, 0-3 side - to place in front of the window
